## Architecture map

`main_window.py` selects the source language and owns session queues → `microphone.py` and `wasapi.py` capture audio → `processing.py`, `source_gate.py`, and `timeline_mixer.py` normalize/select/mix 16 kHz mono PCM → `deepgram_client.py` builds the Deepgram WebSocket request, sends audio, and parses raw events → English/non-Japanese finals flow through `utterance_lifecycle.py`; Japanese finals flow through `japanese_final_chunk_stabilizer.py` and `japanese_sentence_assembler.py` → both converge at lifecycle/identity and `pipeline_commit_transaction.py` → `canonical_transcript_ledger.py` → transcript store/UI/final export. Revision, duplicate, correction, and lineage modules can change the user-visible hypothesis after provider recognition and therefore must be separated from raw STT accuracy when scoring.

## Do NOT treat these as STT production blockers unless proven user-facing

The following are evidence/packaging/validation completion flags. A false, missing, pending, or stale value can mean the diagnostic package is incomplete; it does **not** prove that capture, Deepgram recognition, stable commit, canonical ledger, UI output, or final export failed:

- `stage_capture_complete`
- `validation_output_written`
- `no_finalizer_exceptions`
- `completed_pending_evidence_package`
- evidence index/ZIP freshness or presence
- `latest` pointer synchronization
- report synchronization, upload-package inclusion, cleanup/retention completion
- diagnostic log completeness, sampled interim completeness, stage manifest completeness
- `visible_error_audit` findings, glossary/keyterm warnings, and translation-readiness scores
- profiler/health/stall fields such as missing marks, stale snapshots, or delayed background packaging

Escalate one of these to a production blocker only when it is tied to user-facing evidence such as missing/dropped delivery chunks, missing provider finals, an uncommitted terminal utterance, canonical/final-output divergence, reproducible text loss, or a UI-visible wrong/missing transcript.
