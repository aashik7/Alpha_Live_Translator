# Assets — UI Design Showcase

This folder is reserved for future visual assets used in the UI/UX presentation package.

## Current Status

The prototype (`prototype/`) uses **no external image files**. All visual elements are built with HTML, CSS, and emoji/text labels per the design system.

## Planned Asset Types (Optional Future)

| Asset | Purpose |
|-------|---------|
| `logo.svg` | Alpha Live Translator brand mark |
| `screenshots/` | Static captures of prototype screens for documentation |
| `mockups/` | Higher-fidelity design explorations |

## Guidelines

- Do not include API keys, credentials, or real meeting recordings
- Do not include real user logs or private transcript content
- Use only mock/sample Japanese text for any demo assets
- Keep assets lightweight for easy sharing in presentations

## Adding Assets

When adding files here, update `README_UI_DESIGN.md` if the prototype begins referencing them.
